# Alimayu Studio

Website for Alimayu Studio and speaking requests for Dr. Allison Alimayu.

## Pia chat bubble

Pia is the Jotform AI Agent that walks event organizers through the speaking request form. To show her on a page, keep this line just above the closing `</body>` tag:

```html
<script src='https://cdn.jotfor.ms/agent/embedjs/01a0c235f070700082ffa4bbe5702f0b80e3/embed.js'></script>
```

Standalone link: https://agent.jotform.com/01a0c235f070700082ffa4bbe5702f0b80e3
